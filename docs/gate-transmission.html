The Lamina Seam

How one physiological lamina hands a value to the lamina above it: the absorption vector collapses a composite into a single state value, two independent sets of gates — one on each membrane — decide whether it crosses, and the receiver maps it back into its own units. This note pairs each step of the mechanism with the code that performs it, so the argument can be checked without reading the repository.

Repository cardio-twin Branch universal-visualisation Backend Python · Tests 402 passing Date 3 September 2026

The claim in one paragraph

A lamina is a self-contained model of one physiological system. It computes internally in whatever units its domain uses — millilitres, beats per minute, litres per minute. When it needs to reach the lamina next to it in the stack, none of that internal detail travels. The lamina presents exactly one composite at its interface; the absorption vector weighs that composite's attributes into a single number in [0,1]; and that number is the whole of what the gates see and the whole of what crosses. Neither membrane's gates can name an attribute — the parser refuses a declaration that tries. The receiving lamina then maps the number onto the range it declares, at a rate it chooses, taking as much of the deviation as it permits.

The consequence that matters architecturally: the two laminae are coupled by a contract about a scalar, not by knowledge of each other's internals. A lamina can grow an attribute, rename one, or change how it computes, and nothing on the far side of the seam has to be rewritten.

The seam, end to end

A value crosses only when both membranes are open at the same time. When the sender is open and the receiver is not, the value sits in the channel and ages — a state the earlier single-valve design had no way to represent, and which the system now reports as waiting rather than collapsing into "did not cross".

STAGE 1

Absorption: many attributes become one number

Every attribute in a lamina carries a declared physiological range, and its normalised value is its position in that range, in [0,1]. A composite groups attributes that mean something together. The absorption vector is one weight per attribute in that group, and it is what turns the group into a single figure:

The container never reads attributes on a gate's behalf. It asks the twin for the composite's state value, and packages that with three other facts into a reading — the only object a gate is ever handed:

label is the composite's identifier — the "kind of molecule" a receptor on the far side can recognise. state is the absorbed scalar. delta is how far that scalar moved since the previous cycle, and is None on the first cycle, because a change needs two cycles before it is a measurement rather than a guess. vector is the composite's coordinates, used only by shape-matching keys. saturated names any attribute whose raw value has left its declared range — see the finding in Evidence.

An attribute with no reading yet is dropped along with its weight, rather than being counted as zero. If nothing weighted survives, the composite presents None and any gate reading it stays shut and says why — it does not open on a fabricated floor:

Two properties of that declaration are enforced when the file is parsed. The source of a crossing must be a composite, never a bare attribute. The destination must be an attribute the receiving lamina has itself declared as INTER_LAMINA — a channel cannot write into another lamina's sensor (that would forge a measurement) or into something it computes for itself.

STAGE 3

Control: two membranes, two independent decisions

This is the part most easily misread. The two kinds of gate are not "sender's gate" and "receiver's gate". Both membranes may carry both kinds, up to four gates each. What distinguishes them is what a gate reads, and the distinction follows the ion-channel analogy exactly: a voltage-gated channel opens on the cell's own membrane potential; a ligand-gated channel opens when the right molecule arrives from outside.

Auto gate — reads its own lamina's composite Key gate — reads what is presented at the channel
On the transmit membrane "My own state has left what the far side is assuming." A threshold on the sender's state value. "The far side is asking." Reads the receiving lamina's interface composite as a demand signal.
On the receive membrane "I am in trouble and will take whatever is on offer." A threshold on the receiver's own state value. "Is the thing being offered the right kind, or the right shape?" Reads the label, state and vector the sender put on the channel.

What a threshold is allowed to look at

Three readings of one number, and none of them can name an attribute. The old schema had an aggregate="attr" mode plus a watch="CO" attribute, which let a gate reach past the composite and threshold on a single coordinate. Both are now refused at parse time.

deviation exists because the other two are one-sided. A gate watching the state value itself can only open when that value is high, so a seam described as opening "while the pump is remarkable" would open for a racing heart and stay shut for a failing one. Distance from a declared reference makes both directions the same number.

Not one of those numbers is a matter of taste. reference="0.30" is the receiver's own declared baseline for CO_ref — 5.0 L/min — expressed in the space the wire carries: (5.0 − 2) / (12 − 2). open_above="0.125" comes from the receiver's declared tolerance on oxygen delivery: with DO₂ = CaO₂ · CO_ref · 10 and a measured CaO₂ of 19.80, the cardiac-output error that pushes DO₂ out of its ±250 band is 250/198.0 = 1.262 L/min, which is 0.126 normalised. The seam opens exactly when staying shut would put the far side's own outcome out of range. close_below="0.09" is 3.4 standard deviations of the measured noise on that signal — the first deadband width at which the gate stops arguing with the feed (177 transitions in 400 cycles with one boundary; 1 with this band).

The receiving gate uses identity, which matches the label rather than applying a second threshold. The reasoning is a division of labour: recognising that the pump is failing is circulation's judgement about itself, and it has already been made on the transmit membrane. Respiration only needs to know that what arrived is a cardiac output.

Note the first branch. "Nothing is presented" is not the receiver refusing — it is the receiver having nothing to decide about, because the sender never offered. The two are different news and the system keeps them apart.

Ordering, and what "open" means jointly

On each membrane, auto gates are evaluated first, and when one opens the key gates on that membrane are not consulted at all: a relief valve does not ask the controller for permission. Gates on one membrane sit in parallel — any one open means the membrane is open. An auto gate that fires may flood its own side (weight and rate forced to 1), and says nothing whatever about the far side's gates; a sender's emergency cannot force a receiver open, because that would be a forced write into another lamina arriving through the door marked "safety".

The refractory hold is what keeps the gate from changing its mind on a fast genuine swing, and gives the downstream lamina a few cycles to respond before the decision is revisited. The deadband handles noise; the refractory handles speed.

After both membranes open: what the receiver actually does

Opening is only half of the receiver's authority. Every term on which a value is absorbed belongs to the receiving gate, and the sender can set none of them.

The absorption vector as a dynamic weight matrix

Until this revision the absorption vector was parsed from XML and never touched again — "dynamic weight matrix" described an intention rather than a behaviour. It now adapts each cycle against a declared behavioural outcome, so that the model's own summary of a composite lines up with what the sensors say that outcome is doing.

All four attributes are required together; a learning rate without a clamp is refused at parse. The clamp is the important half, because this loop now sits inside another one: absorption moves the state value, the state value opens a gate, the gate moves CO_ref, CO_ref moves DO₂, and DO₂ is the outcome that moves absorption.

The step is the gradient of the state value with respect to each weight: since s = Σvᵢwᵢ / Σw, we have ∂s/∂wᵢ = (vᵢ − s)/Σw. An attribute already sitting where the state is earns no change — it carries no information about which way to move. Dividing the error by the tolerance is what keeps the rule universal: it is the one form of the error that means the same thing for an outcome measured in mL/min and one measured in mmHg.

Evidence

About these figures

Every number below comes from the model driven by a deterministic synthetic sensor feed (seeded pseudo-random generator, seed 11) — not from patient data, and not from any clinical dataset. They demonstrate the behaviour of the mechanism, not the physiological accuracy of the model. No clinical validation is claimed or implied.

The interface composite must be what the lamina owes the outside

The obvious first choice was to let circulation present pump_state — end-diastolic volume, stroke volume, heart rate and cardiac output, weighted equally. Measured across five weightings, holding the rest of the model fixed, that choice is wrong in a way that only shows up under load:

Averaging the machinery dilutes exactly the signal the seam exists to carry. With equal quarter-weights the deviation at 35 bpm reaches only 0.091 against an opening threshold of 0.125 — the gate never opens for shock, and respiration goes on computing oxygen delivery from its uncoupled baseline of 5.0 L/min, an error of 32% in the direction a clinician would care about most.

The resolution is not to bend weights until a number is agreeable. An interface composite is what a lamina owes the outside, not a summary of everything inside it. End-diastolic volume, stroke volume and heart rate are how a cardiac output gets made; oxygen delivery needs the output. The architecture cost almost nothing in numerical terms

A frozen trace of the previous design — nine scenarios, forty cycles each — is kept in the repository and is never regenerated. Under the composite-only mechanism, seven of the nine scenarios reproduce it exactly, to twelve decimal places. That is not luck: the wire carries a normalised quantity, the receiver maps it back through its own declared range, and because CO and CO_ref declare the same range the round trip is the identity.

The one real cost, stated at full size

Two scenarios diverge, and both for the same reason: the model is driven past the range its own file declares. Held at 200 bpm the circulation computes a cardiac output of 13.2 L/min against a declared maximum of 12. A state value lives in [0,1] by construction — that is what lets one set of thresholds mean the same thing in L/min and in mmHg — so 13.2 normalises to 1.0 and the most the wire can offer is 12.

The finding is not about the seam

275 mL/min is larger than the respiratory lamina's own declared tolerance on oxygen delivery, which is ±250. Both designs are doing the only thing available to them with a number the declaration says is impossible: the previous wire preserved the value and ignored the receiver's declared range; this one honours the range and cannot represent the excess. What the divergence actually measures is that cardiac output's declared maximum of 12 L/min has been outgrown by the model that computes cardiac output. Widening that range is a physiological decision for the domain expert, and was deliberately not taken here. What the seam owes is honesty about it: every trace record and every provenance entry carries saturated, naming the attribute that ran out of declared room.

The learning loop responds, then stops

Two properties make it safe to run a learning loop inside a closed one, and both are measured on the shipped body:

Without the tolerance dead-zone the same 110 bpm run — with the model already comfortably inside its declared band — walked the weights from equal quarters to 0.497 on oxygen saturation with oxygen delivery pinned on its floor, and they were still moving at cycle 200. That is not learning; it is a loop with nothing to converge on, grinding against its own clamps. It is the reason the dead-zone is in the code.

Deliberately left open

  • Shape matching still reads coordinates. A pattern trigger, and the weighted_distance and cosine key metrics, match the shape of a whole composite rather than its single state value. The line drawn here is that a shape match consumes the composite entire, whereas the old watch="CO" picked one attribute and ignored the rest. The failing-pump recogniser in the second body depends on this, and it is a measured capability with its own frozen trace.
  • Where a pattern belongs. The architecture note that prompted this work classifies patterns as a property of the key gate, with the auto gate holding only thresholds. The implementation keeps patterns available on auto gates, on the argument that recognising one's own failure is internal recognition. Moving them would mean rewriting the second body.
  • Cardiac output's declared range. See the saturation finding above. This is a physiological judgement, not an engineering one.
  • Transform functions. Refused rather than implemented, pending a decision on whether "how much passes" should ever be an arbitrary function rather than a scalar weight.
